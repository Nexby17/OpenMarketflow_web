# Paper Lab

Изолированная лаборатория paper-тестов роботов. Боевые роботы (`robot/*.py`) не трогаются.

## Изоляция (4 слоя)

1. **Деньги:** `PAPER_MODE = True` захардкожен в main-файлах lab (реальных ордеров не будет даже без флага)
2. **Сеть:** порты 5180 (SiU6), 5181 (MXU6) — не пересекаются с боевыми 5070/5080/5081
3. **Данные:** state/config — `state/` внутри lab (не трогаем боевые of_state_*.json)
4. **Код:** копии strategy/config живут здесь; общий SDK-слой (finam_compat, orders_dp, orderflow_engine) импортируется из `robot/`

## Запуск

```
cd robot/paper_lab
python3 main_of_mx_paper.py            # paper MXU6, порт 5181 (PAPER_MODE всегда on)
python3 main_of_mx_paper.py --port 5182  # альтернативный порт
```

Статус: `curl http://localhost:5181/status` (тот же JSON, что читает дашборд).
Логи: `logs/YYYY-MM-DD.log`

## Правила

- Любая правка функций здесь → запись в `papercuts.md` (PC-XXX: что/зачем/наблюдения/вердикт)
- Вердикты: PORT (перенести в робота) / DROP (выкинуть) / KEEP (наблюдаем дальше)
- Перенос в `robot/` — только через PORT + отдельный коммит
- Paper-роботы НЕ показываются во вкладке «Роботы» дашборда (чтобы не путать с боевыми)
