## Операционные правила (следствия закона)

1. **Два процесса одного скрипта на одном порту = ВОПРОС Дмитрию**, не решение.
   Никогда не выбирать «какой из них зомби» самостоятельно (ошибка 02.10, :5083).
2. Операция (kill/стейт/стоп/старт) адресуется ТОЧНЫМ именем робота из таблицы +
   портом + стейт-файлом. В отчёте называть робота этим именем.
3. Позиция счёта не приписывается роботу без подтверждения из его журнала.
4. Стейт-файл чужого робота не трогать. Перезапись стейта — только по задаче Дмитрия.
5. F-059-замок (instance_lock.py) делает дубль технически невозможным; если замок
   сработал — это сигнал, что кто-то уже запущен, а не повод его убивать.
