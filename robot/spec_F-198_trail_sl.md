# F-198 — режим Trailing SL для OF-Si (под галкой)

**Статус:** ТЗ согласовано с Дмитрием 18.11.2026. Реализация — после утверждения.
**Область:** `strategy_of.py`, `main_of.py`, UI-панель OF-Si (5080). Старый режим остаётся по умолчанию.

---

## 1. Цель

Заменить фиксацию прибыли маркетом (partial TP по `Spread` и tp_full по `Min Profit/Lot`) на трейлинг-стоп:
прибыль не закрывается сразу, а «запирается» стопом, который идёт за ценой. Режим включается галкой;
при выключенной галке поведение робота не меняется.

## 2. Параметры

### Новые (поля в UI)

| Параметр | Тип | По умолчанию | Смысл |
|---|---|---|---|
| `trail_mode` | bool | `false` | галка «Trailing SL» |
| `trail_sl_pts` | int, пт | 12 | дистанция стопа от Bid/Ask |
| `trail_step_pts` | int, пт | 5 | шаг подтяжки стопа |

### Существующие (используются как пороги)

| Параметр | Текущее | Роль в режиме |
|---|---|---|
| `spread` | 42 | порог активации по-лотового стопа (усреднение) |
| `close_half_pct` | 60 | уровень Close % All (работает при любом значении 10…60) |
| `step_average` | 36 | шаг усреднения (вход, без изменений) |
| `step_pyramid` | 30 | шаг пирамиды (вход, без изменений) |

## 3. Состояние

Для каждого слоя (`LotEntry`) добавляется:

- `uid` — стабильный идентификатор слоя
- `trail_armed` — стоп выставлен
- `stop_order_id`, `stop_px`, `stop_qty`
- `best_px` — лучшая цена в нашу сторону с момента последней перестановки

Агрегированный стоп (Close % All / пирамида):

- `agg_stop_order_id`, `agg_stop_px`, `agg_stop_qty`

Всё состояние стопов сохраняется в `of_state.json` (переживает рестарт).

## 4. Алгоритм

### 4.1 Усреднение — стоп «по лоту»

На каждом тике, для каждого слоя без стопа:

```
pnl_pts = (price - lot.price) * dir
если pnl_pts >= spread:            # 42
    stop_px = Bid - trail_sl_pts   # LONG
            = Ask + trail_sl_pts   # SHORT
    выставить SELL STOP / BUY STOP на lot.lots (1 лот), LAST_DOWN / LAST_UP
    lot.trail_armed = true; lot.best_px = Bid (для LONG) / Ask (SHORT)
```

Трейлинг для уже вооружённого слоя:

```
best = Bid (LONG) / Ask (SHORT)
если (best - lot.best_px) * dir >= trail_step_pts:      # 5 пт в нашу сторону
    новый_stop = best - trail_sl_pts (LONG) / best + trail_sl_pts (SHORT)
    cancel + place на новый объём (1 лот)
    lot.stop_px = новый_stop; lot.best_px = best
```

Правила:
- стоп двигается **только в сторону позиции**, назад — никогда;
- дистанция `trail_sl_pts` (12) всегда считается от **текущего** Bid (LONG) / Ask (SHORT);
- срабатывание стопа закрывает **только этот 1 лот**, остальные слои и их стопы живут дальше.

### 4.2 Close % All — стоп на весь объём

Условие — как сейчас в `_check_partial_tp` для `close_half_pct`:

```
total_lots <= max(2, floor(peak_lots * close_half_pct / 100))
и профит последнего слоя >= spread
```

Действие в режиме `trail_mode`:

1. снять все по-лотовые стопы;
2. выставить **один** стоп на весь оставшийся объём по тем же правилам (`Bid − 12` / `Ask + 12`);
3. дальше трейлить его шагом 5 пт.

### 4.3 Пирамидинг

- **3+ лота, набранные пирамидой:** как только появился третий лот — снять по-лотовые стопы и **сразу**
  выставить один стоп на весь объём (без ожидания порога), далее трейл 5 пт.
- **1–2 лота, набранные пирамидой:** те же правила, что у усреднения (по-лотово, порог `spread`).
- **3+ лота, набранные усреднением (не пирамидой):** остаёмся на по-лотовых стопах;
  агрегированный стоп — только на уровне Close % All.

### 4.4 Прочие выходы

| Механизм | В режиме `trail_mode` |
|---|---|
| partial TP по `Spread` | **отключён** (заменён по-лотовым стопом) |
| tp_full по `Min Profit/Lot` | **отключён** |
| reverse-сигнал CVD | работает |
| VWEMA avg-exit | работает |
| timeout (`max_hold_minutes`) | работает |
| дневной стоп (`stop_loss_*`) | работает (сейчас 30 млн ₽ = фактически выкл.) |
| `close_price_all` | работает |
| закрытие по сессии | работает |
| PYR STOP (F-193) | в режиме не используется — его роль играет трейлинг |

## 5. Исполнение и учёт

- **Определение, какой стоп сработал:** по `order_id` из WS ORDERS (`_on_my_trade`).
  Совпадение с `lot.stop_order_id` → снять слой из очереди, записать сделку с `reason='trail_sl'`,
  удалить запись из реестра.
- **Агрегированный стоп** исполнен → позиция FLAT, полный сброс.
- **Десинк-монитор (F-095):** при активных трейл-стопах не делать full-resync мгновенно.
  Сначала сверить «ожидаемый объём = lots робота − исполненные стопы», дать 2–3 сек на обработку WS;
  full-resync только если расхождение не объясняется исполненными стопами.
- **Рестарт:** из state восстановить реестр стопов; сверить с брокером (`get_orders`):
  живые — оставить и продолжить трейлинг, осиротевшие — отменить, отсутствующие — переставить
  (с учётом F-194: не ставить за рынком).
- **Журнал:** причина закрытия `trail_sl` (или `trail_sl_agg`), в комментарии заявки — тег `of_trail_sl`.

## 6. Ограничения и защита

1. **F-194** — стоп никогда не выставляется за рынком: LONG `stop_px >= Bid` или SHORT `stop_px <= Ask` → не ставим.
2. **F-195** — перед любым закрытием сверка с брокером (защита от двойного закрытия).
3. **Дебаунс перестановок:** не чаще 1 раза в 1.5–2 сек на заявку (шаг 5 пт сам ограничивает частоту).
4. **Лимит активных стоп-заявок Finam** — проверить; при превышении объединять соседние слои в одну заявку (по 2–3 лота).
5. **Округление цены** — до целого (шаг Si = 1), правило F-136.
6. **Устаревшие котировки** — если Bid/Ask старше N сек, трейлинг не двигаем (защита от дёрганья по мусору).
7. **Пирамида и агрегат:** при снятии по-лотовых стопов сначала cancel, потом place — без окна, когда стопов нет,
   либо place нового до cancel старого с последующей отменой (предпочтительно: окно перекрытия безопаснее).

## 7. Тест-план

Юнит-тесты (`robot/test_of_trail_sl.py`):

1. активация по-лотового стопа при +`spread` (LONG и SHORT);
2. до порога стопа нет;
3. трейлинг шагом 5: сдвиг в нашу сторону, назад — никогда;
4. срабатывание одного стопа из трёх → закрыт 1 лот, остальные стопы живы;
5. Close % All → все по-лотовые сняты, один агрегат на остаток;
6. пирамида: 3-й лот → агрегат сразу, без порога;
7. 3 лота усреднением → остаются по-лотовые, агрегата нет;
8. F-194: уровень за рынком → стоп не ставится;
9. рестарт: реестр стопов восстанавливается из state;
10. выключенная галка → поведение старого режима (регресс partial TP / tp_full).

Регресс: `test_of_pyramid_stop_levels.py` 17/17, `test_of_pending_signal.py` 11/11,
`test_of_pyramid_full_exit.py` 14/14, `test_of_timing.py` 11/11, `test_of_vah_val_range_v2.py` 7/7.
