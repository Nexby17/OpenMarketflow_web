## Key logic changes

### Price source priority (robot/main.py tick loop)
1. `/position?account=X&ticker=Y` → current_price from broker REST (ALWAYS fresh)
2. `/quote/SYMBOL` → only if timestamp < 60s old (stale guard)
3. Fallback: feed price

### Entry price priority (entry fill detection)
1. `_broker_avg` — from REST position API (real execution price)
2. `_get_last_fill_price()` — from recent-fills API
3. `_entry_pending_price` — price at signal time (last resort)

### Trade journal PnL (app.js)
- Before: (exit - avg_entry) × lots × direction - commission (wrong for grid)
- After: sum(sell proceeds) - sum(buy cost) - commission (matches broker)

### Unrealized PnL (get_status)
- Before: (price - entry) × lots (no grid fills, no commission)
- After: (price - avg_entry) × lots × direction - commission

### Close position PnL
- Before: calc_unrealized_pnl() (stale method)
- After: same avg_entry method as get_status + broker PnL override
