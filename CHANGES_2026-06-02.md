## Key logic

### Price source priority (tick loop)
1. `/position?account=X&ticker=Y` → current_price (ALWAYS fresh from broker)
2. `/quote/SYMBOL` → only if timestamp < 60s old
3. Fallback: feed price

### Entry price priority (entry fill)
1. `_broker_avg` — from REST position (real execution price)
2. `_get_last_fill_price()` — from recent-fills
3. `_entry_pending_price` — signal time (last resort)

### PnL calculations
- **Unrealized**: `(price - avg_entry) × lots × direction - commission`
- **PnL/lot**: `(price - avg_entry) × direction - commission` (per lot)
- **Realized**: accumulated per-trade, reset on new entry
- **Close trigger**: PnL/lot >= min_profit_per_lot (any number of lots)

### Stop button
1. Cancel all orders
2. Get real broker position
3. Close market if lots > 0
4. Kill process (for instances)

## Additional fixes (17:50-18:10 UTC)

### Close condition rewritten
- **Before**: PnL/lot = unrealized / lots, close when >= min_profit (separate for 1 lot and 2+ lots)
- **After**: trade_pnl = realized + unrealized, close when >= min_profit × lots
- Example: 30₽ × 5 lots = 150₽ threshold
- POC hit still works as separate exit (any lot count)

### Entry/grid fill prices from broker
- Entry fill: price from `/api/trades` (real execution price, not feed)
- Grid fill: price from `/api/trades` (not pending grid price)
- avg_entry = sum of real prices / lots = matches broker

### Realized PnL per trade
- `realized_pnl` resets to 0 on new entry
- Accumulates from TP fills and round trips within current trade

### Stop button (final fix)
- C# `/api/robot/service/stop`: calls robot `/stop` first (closes position), waits 2s, then `systemctl stop`

### API response fields
- `pnl`: trade PnL (realized + unrealized), 0 when no position
- `pnl_per_lot`: (price - avg_entry) × direction - commission
- `unrealized_pnl`: pure unrealized from current position

## Fix 04.06.2026 13:21 UTC — max_lots threshold (commit aea2198)

### Close threshold uses max_lots
- _max_lots tracks peak position size during trade
- threshold = min_profit × max_lots (e.g. 30×5=150, not 30×3=90)
- Prevents premature close when TP fills reduce lot count
- Resets to 0 on new entry and on close
- POC hit still works at 1 lot (independent of max_lots)

### Example
- Entry + 4 grids = 5 lots, max_lots=5
- TP fills reduce to 3 lots, realized=62₽
- Old: threshold = 30×3 = 90 → trade_pnl=126 → premature close
- New: threshold = 30×5 = 150 → trade_pnl=126 → continue trading
