# Архитектура HedgeFund Robot

## Обзор

Мультиброкерный торговый робот с поддержкой усреднения, индикаторных стратегий и гибким UI-управлением.

## Брокеры
- **Финам** — через Transaq Connector (XML API)
- **Альфа-Инвестиции** — через PRO API (protobuf/channels)

## Логика усреднения

```
Сигнал → Открытие позиции (1 лот по умолчанию)
│
├── PnL > 0 → Закрытие всей позиции
│
└── PnL < 0 + новый сигнал:
    └── Усреднение (добавка к позиции)
        ├── Режим «Фикс»: +1 лот каждый раз
        ├── Режим «Мартингейл»: 1→2→4→... (переключается кнопкой)
        │
        └── После усреднения:
            ├── PnL > 0 → Закрытие ВСЕЙ усредненной позиции
            └── PnL < 0 → ждём следующий сигнал

Настройки через UI:
- [Вкл/Выкл] Лимит усреднений (макс. кол-во добавок)
- [Вкл/Выкл] Мартингейл vs фиксированный объём
- [Вкл/Выкл] Стоп-лосс на всю позицию
- Размер стоп-лосса (% или пункты)
```

## Стек
- **Язык:** C# (.NET 8)
- **UI:** WPF (Windows)
- **Тестирование:** xUnit + свой бэктестер
- **Данные:** SQLite для логов / истории
